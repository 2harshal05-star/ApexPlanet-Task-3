# ApexPlanet Internship – Task 3

## Deep-Dive Analysis & Interactive Dashboarding

This project focuses on analyzing sales data and building an interactive dashboard using Microsoft Power BI.

### Project Overview
The dashboard provides insights into sales performance across different cities, product categories, and years.

### Key Performance Indicators
- **Total Revenue:** Total sales generated.
- **Average Sales:** Average sales value per record.
- **Total Quantity:** Total units sold.
- **Total Customers:** Number of unique customers.

### Analysis
- Sales by City
- Sales by Category
- Sales by Year
